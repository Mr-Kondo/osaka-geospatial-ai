# ADR-001: NotebookをPresentation Layerに限定

- Status: Accepted
- Date: 2026-09-19

## Context

Colabでの試行中に処理ロジックがセルへ分散すると、個別CLI実行・テスト・再実行の結果が一致しにくい。

## Decision

Notebookはrepository setup・依存導入・script実行・成果物表示のみとする。Pythonの関数・クラス定義、設定解決、GPU判定、GIS変換、学習、推論は置かない。設定と実行環境の読み取り専用表示を含む表示整形は `presentation.py` へ置く。

## Consequences

セル単体の自由な分析は減るが、同じpipelineをローカルでも実行できる。NotebookのAST、禁止操作、`osaka_geo_ai.presentation` 以外のdomain importを契約テストで検査する。
