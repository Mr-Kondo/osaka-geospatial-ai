# ADR-001: NotebookをPresentation Layerに限定

- Status: Accepted
- Date: 2026-09-19

## Context

Colabでの試行中に処理ロジックがセルへ分散すると、個別CLI実行・テスト・再実行の結果が一致しにくい。

## Decision

Notebookは環境準備・設定・script実行・成果物表示のみとする。Pythonの関数・クラス定義、GIS変換、学習は置かない。表示整形はpresentation.pyへ置く。

## Consequences

セル単体の自由な分析は減るが、同じpipelineをローカルでも実行できる。NotebookのASTを検査し、全セルの実行も確認する。
