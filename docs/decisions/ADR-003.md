# ADR-003: VLMと数値GIS解析を分離

- Status: Accepted
- Date: 2026-09-19

## Context

画像からの正確な統計計算や視覚的対応からの因果断定は信頼できない。

## Decision

統計・距離・割合・誤差はPythonが算出する。VLMは4枚の静的地図から可視パターンのみを観察し、Pydanticで構造検証する。画像hashとstatusを保存する。

## Consequences

構造検証は意味的な正しさを保証しない。失敗時に観察を埋めず、空配列と理由を返す。初期候補はApache 2.0、GPU負荷を考慮したQwen2-VL-2Bを設定可能なprovider経由で使用する。
