# ADR-004: Structured JSONをLLM Interfaceとする

- Status: Accepted
- Date: 2026-09-19

## Context

生の空間テーブルは大きく、計算値と生成文の区別が曖昧になりやすい。

## Decision

観測統計・ML指標・残差・VLM所見・限界・出典をanalysis.jsonへ集約し、LLMの唯一の主入力とする。数値に基づく定型説明を保持し、生成文章は未検証の別節とする。

## Consequences

LLM無効・利用不能時もレポートが完成する。その文章をLLM出力とは呼ばない。失敗やtruncateの状態を別JSONに残す。
