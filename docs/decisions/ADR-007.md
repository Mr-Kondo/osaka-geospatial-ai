# ADR-007: 洪水の未収録と区域外を区別

- Status: Accepted
- Date: 2026-09-19

## Context

浸水想定区域は河川・シナリオごとに収録範囲が異なる。ポリゴンに当たらない地点を一律に安全と扱えない。

## Decision

標準では洪水を無効とする。任意の深度ポリゴンと評価済み範囲の2つのGeoParquetを入力契約にする。範囲外はnull、範囲内の非該当だけ0。

## Consequences

A31生ZIPの自動正規化・実データ検証は未実装。ダウンロード不能とは主張しない。版別の深度コードと範囲を確定する作業が追加で必要。
