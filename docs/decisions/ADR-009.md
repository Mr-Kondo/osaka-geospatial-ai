# ADR-009: Google Colabを標準実行環境とする

- Status: Accepted
- Date: 2026-09-19

## Context

利用者にローカルGIS・CUDA環境の構築を前提とすると、OS、GDAL系wheel、GPU driver、モデルキャッシュの差が最初の障壁になる。一方、Notebookへ処理ロジックを移すと責任分界と再現性を失う。

## Decision

Google Colabを標準の実行入口とする。Notebookは公開GitHubリポジトリをcloneし、依存関係、公式GISデータ、Hugging Faceモデルを取得したうえで、repository内の `scripts/run_pipeline.py` を実行する。GIS・ML・AIロジックは引き続き `src/` と `scripts/` に限定する。

ローカル実行は任意経路とし、利用者はGitHubからclone後、仮想環境を作成して実行する。AIを無効にした `configs/default.yaml` と、CUDA、Apple Silicon MPS、CPUの順に自動選択する `configs/ai.yaml` を維持する。

## Consequences

標準手順はColabでGPUを選び全セルを実行するだけになる。Colabランタイムは一時的なため、セッション破棄後はデータとモデルを再取得する。ローカル利用者は環境差を自分で管理するが、Notebook固有の処理実装には依存しない。
