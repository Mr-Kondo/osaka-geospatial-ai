# ADR-008: 年別スキーマと成果物の整合性を検証

- Status: Accepted
- Date: 2026-09-19

## Context

L01は2022年・2024年に列構造が変わり、2021年ZIPにはWindows区切りのパスがある。同じ列番号を全年度へ使うと誤読する。

## Decision

実ファイルで確認した年別列対応をconfigへ保存。CRSと必須列を検証し、対象shapeの付属ファイルだけ安全に展開する。特徴量・モデル・予測・地図をhashで接続する。

## Consequences

新しいデータ版にはmappingとchecksumの確認が必要。stale artifactは停止して再作成する。並列の同一出力先実行はサポートしない。
