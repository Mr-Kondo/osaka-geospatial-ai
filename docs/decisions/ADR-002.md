# ADR-002: 地価地点を分析単位として採用

- Status: Accepted
- Date: 2026-09-19

## Context

目的変数は標準地の価格であり、行政区平均からは地点固有の駅距離や土地利用が失われる。

## Decision

地価地点×年のパネルを使用。各年の公開ファイルだけからその年の特徴量を読み、前年番号・選定区分・用途・50m以内の位置で接続する。targetは翌年価格/当年価格-1。

## Consequences

標準地番号変更を追跡できるが、移動・新設・欠年はラベルから除外される。全土地を代表するとは言えない。旧版で行政区変更を照合できない場合は除外する。価格水準へ切り替える必要はなく、変化率targetを採用した。
