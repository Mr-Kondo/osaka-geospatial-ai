# ADR-005: temporal splitを使用

- Status: Accepted
- Date: 2026-09-19

## Context

地価は継続地点の年次データで、ランダムsplitは未来ラベルや同時期の情報を学習へ混入させやすい。

## Decision

target_yearで分割。2022〜2023ラベルで学習、2024で選択、2024まで再学習後に2025を評価。全前処理は各fold内でfitする。翌年想定予測は別モデルで作る。

## Consequences

test指標でモデルを選ばない。rollingはモデルごとに独立した過去年学習を行う。同一地域の将来予測であり、未知地域の評価ではない。厳密な公表日ではなく年単位の利用可能時期なので、その限界を残す。
