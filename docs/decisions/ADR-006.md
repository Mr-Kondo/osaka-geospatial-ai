# ADR-006: 補助データの版と利用可能年を固定

- Status: Accepted
- Date: 2026-09-19

## Context

最新の人口・交通・土地利用を過去の学習へ使うと未来の情報が混ざる。H30人口版には後年訂正、R6版には遅い公表時期の問題がある。

## Decision

人口H29推計、鉄道2020、土地利用2016を採用し、available_from_yearで過去年をnullにする。人口は2010基準値と将来推計を列名から区別する。全ZIPのSHA256と取得日時を保存する。

## Consequences

データは古い。利用可能年は保守的な年次設定であり、当時の配布ファイル全履歴を保証しない。2024行政区域は背景表示のみ。固定ハッシュ変更は自動受容しない。
